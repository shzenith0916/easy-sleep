# 비디오 파일명 변경 도구

## 개요
이 도구는 서브폴더에 있는 .avi 파일들의 이름을 해당 서브폴더의 사람 이름으로 자동 변경하는 스크립트입니다.

## 파일 구조 예시
```
3-1)moderate/
├── 김철수_자료/
│   └── Video_Clip0001.avi
├── 박영희(test)/
│   └── Video_Clip0001.avi
└── 이민수_20230901/
    └── Video_Clip0001.avi
```

## 변경 결과

### 1. 마스킹 모드 (김철수 -> 김*수)
```
3-1)moderate/
├── 김철수_자료/
│   └── 김*수_Video_Clip0001.avi
├── 박영희(test)/
│   └── 박*희_Video_Clip0001.avi
└── 이민수_20230901/
    └── 이*수_Video_Clip0001.avi
```

### 2. 완전 제거 모드 (김철수 -> Person)
```
3-1)moderate/
├── 김철수_자료/
│   └── Person_Video_Clip0001.avi
├── 박영희(test)/
│   └── Person_Video_Clip0001.avi
└── 이민수_20230901/
    └── Person_Video_Clip0001.avi
```

### 3. 익명화 없음 (기존 방식)
```
3-1)moderate/
├── 김철수_자료/
│   └── 김철수_Video_Clip0001.avi
├── 박영희(test)/
│   └── 박영희_Video_Clip0001.avi
└── 이민수_20230901/
    └── 이민수_Video_Clip0001.avi
```

## 사용 방법

### 방법: Python 스크립트 직접 실행
1. `rename_videos.py` 파일을 "3-1)moderate" 폴더가 있는 디렉토리에 복사
2. 명령 프롬프트에서 해당 디렉토리로 이동
3. 다음 명령어 실행:
   ```bash
   python rename_videos.py
   ```
4. 익명화 모드 선택:
   - **1번**: 마스킹 모드 (김철수 → 김*수)
   - **2번**: 완전 제거 모드 (김철수 → Person)  
   - **3번**: 익명화 없음 (김철수 → 김철수)

## 주요 기능

### 1. 미리보기 기능
- 실제 파일명 변경 전에 어떤 파일들이 어떻게 변경될지 미리 확인
- 변경 사항을 검토한 후 진행 여부 결정

### 2. 안전한 이름 추출
- 폴더명에서 특수문자, 숫자, 괄호 등을 제거하여 사람 이름만 추출
- 공백은 언더스코어로 변경하여 파일명에 적합하게 처리

### 3. 오류 처리
- 파일이 존재하지 않거나 접근할 수 없는 경우 오류 메시지 출력
- 변경 과정에서 발생하는 문제들을 개별적으로 처리

## 이름 추출 규칙

폴더명에서 사람 이름을 추출할 때 다음 규칙을 적용합니다:

1. **특수문자 제거**: 괄호, 하이픈, 언더스코어 등 제거
2. **숫자 제거**: 날짜, 번호 등 숫자 제거
3. **공백 정리**: 앞뒤 공백 제거 후 중간 공백은 언더스코어로 변경
4. **한글/영문 유지**: 한글, 영문자만 유지

### 예시
- `김철수_자료` → `김철수`
- `박영희(test)` → `박영희`
- `이민수_20230901` → `이민수`
- `John_Smith_Data` → `John_Smith`

## 주의사항

1. **백업 필수**: 작업 전 원본 파일들을 백업하는 것을 권장합니다.
2. **파일 중복**: 같은 이름의 파일이 이미 존재하는 경우 오류가 발생할 수 있습니다.
3. **권한 문제**: 파일 수정 권한이 없는 경우 작업이 실패할 수 있습니다.

## 문제 해결

### Python이 설치되지 않은 경우
- Python 3.x 버전을 설치해야 합니다.
- [Python 공식 웹사이트](https://www.python.org/downloads/)에서 다운로드

### 디렉토리를 찾을 수 없는 경우
- 스크립트가 "3-1)moderate" 폴더와 같은 디렉토리에 있는지 확인
- 또는 스크립트 실행 시 올바른 디렉토리 경로를 입력

### 파일명 변경 실패
- 파일이 다른 프로그램에서 사용 중인지 확인
- 파일 및 폴더에 대한 쓰기 권한이 있는지 확인
